# Level 5 Cheat Sheet: Scaling & Organizational Impact

---

## Many Hats (Module 5.1)

### Role Mode Diagnosis
```
I'm facing this situation: [describe]
Which SM role mode should I activate?
Options: Facilitator, Coach, Impediment Remover, Change Agent, Servant Leader, Trainer, Bridge.
Explain why and what specific actions this role mode requires.
```

### Phase-Based Strategy
```
My team is in [forming/storming/norming/performing] stage.
Current challenges: [list]
What should my SM emphasis be at this phase?
What activities should I increase? Decrease? Stop?
```

### SM-to-RTE Transition Plan
```
I'm transitioning from SM (1 team) to RTE-like role (program of [X] teams).
Help me create a 90-day plan:
Month 1: Learn the landscape
Month 2: Establish cadences
Month 3: Drive improvements
For each month: key activities, relationships to build, metrics to track, risks.
```

## Multi-Team Coordination (Module 5.2)

### SoS Preparation
```
Prepare a SoS brief from these team statuses:
[Paste each team's status]
Generate: cross-team blockers, shared dependency risks, decisions needed this week, information each team needs from others.
Single page, prioritized.
```

### Dependency Map
```
Map dependencies across these teams:
[List teams and their current work]
Identify: who depends on whom, critical path items, shared resources at risk, suggested sequencing to minimize blocking.
```

### Resource Conflict Resolution
```
Two teams both need [shared resource] urgently.
Team A's need: [description, impact if delayed]
Team B's need: [description, impact if delayed]
Help me: (1) Compare impact objectively, (2) Generate 3 resolution options, (3) Prepare negotiation talking points for both SMs.
```

### Program Sprint Report
```
Generate a program-level report from these team reports:
[Paste individual team reports]
Include: RAG status per team, cross-team metrics summary, top 3 program risks, decisions needed from leadership, overall trajectory.
```

## Organizational Change (Module 5.3)

### Pattern Aggregation
```
Here are impediment logs from [X] teams:
[Paste or summarize]
Identify organizational-level patterns (issues affecting 2+ teams).
For each: teams affected, frequency, estimated total cost, root cause analysis.
```

### Business Case Builder
```
Build a business case for [proposed change].
Problem: [quantified impact across teams]
Solution: [proposal]
Generate: executive summary, cost-benefit analysis, implementation timeline, risk assessment, recommendation.
Format for [audience].
```

### Influence Map
```
I need to get approval for [proposal] from [organization].
Key stakeholders: [list with roles]
Map each stakeholder: power level (high/medium/low), interest level, likely stance (champion/supporter/neutral/blocker), engagement strategy.
Create a sequenced engagement plan.
```

### Executive Pitch (5 minutes)
```
I have 5 minutes with [executive name, title].
I want to propose: [change]
Their priorities: [what they care about]
Structure my pitch: Hook (15 sec), Problem (60 sec), Data (60 sec), Proposal (60 sec), Ask (30 sec), Close (15 sec).
Use their language, not mine.
```
