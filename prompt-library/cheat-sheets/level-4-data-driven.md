
## Predictive Intelligence (Module 4.2)

### Mid-Sprint Signal Scan
```
Day [X] of Sprint [Y]. Remaining: [Z] points.
Standup themes this week: [summary]
Blockers: [list]
Board status: [X] in progress, [Y] in review, [Z] not started

Predict: Will we meet the sprint goal? Flag early warning signals.
Recommend: Actions to take today if we're at risk.
```

### Correlation Check
```
I notice [correlation in data]. Before I act on this:
1. Is this likely a real causal relationship, or just correlation?
2. What confounding variables might explain this?
3. How would I test whether this is causal?
4. What's the risk of acting on a false correlation?
```

### Intervention Playbook Entry
```
Create an intervention playbook entry for this early warning signal:
Signal: [description]
Trigger threshold: [when to act]
Generate: first response, escalation criteria, success metric, failure mode.
```

## Measuring Impact (Module 4.3)

### SM Value Chain
```
Map this SM activity to its downstream business impact:
Activity: [what I did]
Build the chain: activity → team outcome → delivery impact → business result → dollar value (estimate)
```

### ROI Calculation
```
Calculate the ROI of this SM intervention:
Intervention: [description]
Before: [metric]
After: [metric]
Team size: [X], loaded cost per hour: $[Y]
Calculate: time saved, quality improved, or risk reduced in dollar terms.
```

### Executive Update
```
Write a quarterly SM update for [executive name, title].
Data: [attach metrics]
Rules: Zero agile jargon. Lead with business outcomes. 1 page max.
Include: delivery reliability, risk reduction, team stability, next quarter focus.
```
