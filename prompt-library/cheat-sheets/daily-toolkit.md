# SM Daily Toolkit — Your AI-Augmented Rhythm

Copy-paste these prompts as part of your daily, weekly, and quarterly SM practice.

---

## Morning Routine (10 min)

### Signal Scan (5 min)
```
Analyze these standup notes from the last 3 days for the Velocity Squad:

[Paste standup notes]

Flag:
1. Anyone blocked for 2+ consecutive days
2. Recurring themes or complaints
3. Anyone saying "no blockers" but with no stories moving
4. Scope or requirement questions increasing
5. Any change in communication tone or energy

Rate overall team health: Green / Yellow / Red with reasoning.
```

### Standup Prep (5 min)
```
Based on our Sprint [X] board status and yesterday's standup, prepare me for today's standup:

1. Stories at risk (not progressing or approaching sprint end)
2. Blockers I should follow up on
3. 1 question I should ask the team today
4. Any cross-team dependency to flag
```

---

## During Ceremonies

### Quick Retro Prompt
```
I'm facilitating a [DURATION]-minute retro for [TEAM SIZE] people after Sprint [X].

Sprint goal: [Met/Partially/Not met]
Key event: [1-2 sentence summary of what happened this sprint]

Give me:
1. An icebreaker (2 min)
2. 3 targeted discussion questions
3. A voting/prioritization method for action items
4. A closing activity (2 min)
```

### Quick Planning Prompt
```
Sprint [X] planning for [TEAM NAME]. Capacity: [X] points.

Top of backlog:
[List top 10 stories with points]

Known constraints:
- [team member] availability: [details]
- [dependency or risk]

Suggest: Which stories to pull in, risks to flag, questions to ask the PO.
```

---

## After Ceremonies (5 min)

### Process Notes
```
Process these ceremony notes into:
1. Summary (5-7 sentences for Slack)
2. Action items: [ ] Action — @Owner — Due: Date
3. Decisions made (with rationale)
4. Risks flagged
```

### Generate Follow-Ups
```
For these action items, generate a brief Slack reminder for each owner.
Keep it friendly and under 3 sentences:

[Paste action items]
```

## Weekly (Friday, 15 min)

### Impediment Report
```
Here's this week's impediment activity:

New: [list]
Resolved: [list]
Open: [list with age in days]

Generate:
1. Status summary for stakeholders
2. Any impediment open 5+ days that needs escalation
3. Patterns across open impediments
```

### Health Check
```
Mid-sprint check for Sprint [X], Day [Y] of [Z]:
- Burndown: [X] points remaining
- Blockers: [list]
- Team energy (my observation): [high/medium/low]

Am I on track for the sprint goal? What should I do today?
```

### Reflective Journal
```
My SM week in review:
1. [What happened]
2. [What happened]
3. [What happened]

What patterns do you see? Where am I growing? What should I focus on next week?
```

## Quarterly (2 hours)

### Impact Portfolio Update
```
Update my SM impact portfolio for [Quarter]:

METRICS:
- Velocity trend: [data]
- Sprint goal achievement: [X/Y sprints met]
- Health score trend: [data]
- Impediment resolution time: [data]

KEY INTERVENTIONS:
1. [What I did] → [What changed] → [Quantified impact]
2. [What I did] → [What changed] → [Quantified impact]

Generate a 1-page executive summary of my impact this quarter.
```

### Practice Assessment
```
Based on my monthly reflections from this quarter:

[Paste 3 monthly summaries]

Assess my growth against the AI-Enabled SM Competency Model:
1. Where have I grown most?
2. Where am I stuck?
3. What should I focus on next quarter?
4. One stretch goal to push my development.
```
